# Review guide

Read by the Claude and Codex reviewers, alongside `CLAUDE.md`. When a review comment keeps coming back, add the rule here or to `CLAUDE.md`.

## Report

Report only problems that should block the merge. Each one needs `file:line` and a concrete input or state that leads to the wrong result. Don't report style, naming, formatting or refactors.

Start the summary with the number of blocking findings. If nothing needs fixing, say so in one line.

## What failure means here

| Area | Failure |
|---|---|
| Signing, keys, recovery words, PIN | A secret leaks to logs, analytics or a Mini App. The signed recipient or amount differs from what the user confirmed. |
| HTLC and cosigner | Funds stay locked or are lost. A newer signer gets replaced. A recoverable HTLC is never recovered. |
| Balances, history, sync | The app shows a wrong balance or an empty list when the data is on disk. Listeners register twice. Power users with thousands of transactions stall. |
| USDT and swaps | A transfer or swap is sent twice, or is reported as failed when it went through. |
| SQLite migrations | An existing `CREATE TABLE` was edited, or a migration fails on data from an older app version. |
| Mini Apps host and bridge | A Mini App signs or reads data without the user's confirmation, gets around an origin check, or loses a provider method it depends on. |
| OTA and release | A bundle needs native code the installed app doesn't have, or an update can't be rolled back. |
| Native config and patches | A release build crashes in a way debug builds don't show, such as the R8 case in `CLAUDE.md`. |
| CI workflows | Untrusted PR code gets access to secrets or write tokens. A required check stops running. |

## Sensitive paths

A change to any of these needs `HUMAN REVIEW: required`:

- `src/lib/sql-queries.ts` and migrations
- `src/stores/remote-signer*`, `src/stores/sync/`
- `src/stores/polygon-usdt.ts` and swap code
- `src/composables/useMiniApp*`, `src/lib/mini-app-*`, `web3-provider/`, `vendor/trust-web3-provider`
- Key, signing and PIN code
- `.github/workflows/`
- `ota.json` and release config
- `android/` and `ios/` config, `patches/`

## Skip

- `src/i18n/*.po`, generated by `pnpm i18n:extract`
- Lockfiles: `pnpm-lock.yaml`, `web3-provider/pnpm-lock.yaml`, `mini-app-sdk/dapp/pnpm-lock.yaml`, `ios/App/Podfile.lock`, `Gemfile.lock`
